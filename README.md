# KNU CSE Notice Telegram Bot

경북대학교 컴퓨터학부의 다음 게시판에서 새 글을 확인해 텔레그램
구독자에게 전송합니다.

- 학부 공지사항
- 대학원 공지사항
- 학부인재모집

각 게시판의 마지막 글 번호를 독립적으로 관리하므로, 한 게시판의 글
번호가 더 크더라도 다른 게시판의 새 글을 빠뜨리지 않습니다.

새 공지가 등록되면 다음 내용을 순서대로 보냅니다.

- 실제 공지 제목
- 공지 본문 전체 (원문의 굵게, 기울임, 밑줄, 취소선, 링크, 목록 등 유지)
- 표는 한글 폭과 병합 셀을 반영한 고정폭 코드 블록으로 변환
- 긴 글은 서식을 깨뜨리지 않도록 여러 메시지로 자동 분할
- 본문에 포함된 이미지
- 첨부파일
- 원문 링크

실행에는 `TELEGRAM_TOKEN` 환경변수가 필요합니다.
